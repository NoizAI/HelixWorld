# Contributing to HelixWorld

This repository is a **placeholder** until weights and code are released. There is nothing to compile, and we are not taking implementation PRs yet.

## What to open

| You want to… | Use |
| --- | --- |
| Ask for a capability in 1.0 or later | [Feature request](https://github.com/NoizAI/HelixWorld/issues/new?template=feature_request.yml) |
| Report a problem with this repo (docs, links, license) | [Bug report](https://github.com/NoizAI/HelixWorld/issues/new?template=bug_report.yml) |
| Discuss research directions | A feature request or a plain issue is fine |

Please search existing issues first. Duplicate requests will be closed with a pointer.

## After the code drop

When inference lands, we will update this file with environment, style, and test requirements. Until then:

- Do not send model-weight files, training logs, or third-party checkpoints in issues or PRs.
- Do not paste secrets, API keys, or private datasets.
